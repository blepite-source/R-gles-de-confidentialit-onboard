# Règles de confidentialité

Cette page contient la politique de confidentialité pour notre application mobile, destinée à être publiée sur le Play Store.

## 📄 Fichiers

- **index.html** : Page de politique de confidentialité en français, prête à être hébergée

## 🌐 Accès à la politique

Une fois que vous activez GitHub Pages pour ce dépôt, la politique de confidentialité sera accessible à l'adresse :
```
https://[votre-nom-utilisateur].github.io/R-gles-de-confidentialit-onboard/
```

## 🚀 Activation de GitHub Pages

1. Allez dans les **Settings** de ce dépôt
2. Dans le menu de gauche, cliquez sur **Pages**
3. Dans **Source**, sélectionnez la branche `main` (ou `master`)
4. Sélectionnez le dossier `/root`
5. Cliquez sur **Save**
6. Votre page sera disponible en quelques minutes

## ✏️ Personnalisation

Avant de publier, n'oubliez pas de personnaliser les éléments suivants dans `index.html` :

- [ ] Date de dernière mise à jour
- [ ] Informations de contact (email, adresse)
- [ ] Sections spécifiques en fonction des données réellement collectées par votre application
- [ ] Nom de l'application (si vous souhaitez le mentionner)

## 📱 Utilisation pour le Play Store

Pour soumettre votre application sur le Play Store :

1. Activez GitHub Pages (voir instructions ci-dessus)
2. Copiez l'URL de votre page de politique de confidentialité
3. Dans la Console Google Play, lors de la soumission de votre application :
   - Accédez à **Contenu de l'application** > **Politique de confidentialité**
   - Collez l'URL de votre page de politique
